# Paradise Nursery Shopping Application

Paradise Nursery is an online e-commerce platform for houseplant enthusiasts. Built using React and Redux Toolkit, this application allows users to browse a curated selection of plants, view details, manage a shopping cart dynamically, and calculate order totals in real time.

## Project Features
- **Landing Page**: Modern landing screen with background imagery and quick navigation.
- **Product Catalog**: Categorized houseplants with image, description, price, and dynamic "Add to Cart" state.
- **State Management**: Redux Toolkit for seamless cart updates and quantity manipulation.
- **Cart Summary**: Real-time pricing calculations, quantity increments/decrements, item deletion, and checkout placeholders.
